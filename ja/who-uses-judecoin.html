誰が Judecoin を使っていますか？

Judecoin は、プライバシー、分散化、検閲耐性、開かれたデジタルマネーを重視する人々に使われています。

JUDE は、個人、ウォレットユーザー、Service Node 運用者、開発者、研究者、事業者、企業、インフラ運用者、ドキュメント貢献者、コミュニティメンバーによって使用できます。

一つのネットワーク。4つの参加方法

Judecoin は、通貨を使う人、インフラを運用する人、システムを改善する人、エコシステムを理解しやすく普及しやすいものにする人々を結びつけます。

ネットワークを使う

個人、ウォレットユーザー、事業者、決済ユーザーは、JUDE をプライベートな電子キャッシュおよび直接的なデジタル価値移転として利用します。

ネットワークを運用する

Service Node 運用者とインフラ運用者は、安定性、稼働時間、監視、公開ネットワークツールを支えます。

システムを改善する

開発者と研究者は、ウォレット、daemon、RPC 連携、プライバシー研究、セキュリティ、クロスチェーンツールを強化します。

普及を広げる

企業、ドキュメント貢献者、コミュニティ貢献者、新規ユーザーは、エコシステムをより有用で参加しやすいものにします。

ネットワークを支える人々

プライベート決済やウォレットから、インフラ、研究、ドキュメント、コミュニティ成長まで、あらゆる役割がエコシステム内の異なる位置から Judecoin を支えています。

ネットワークを使う

人々と事業者は、JUDE をプライベートな電子キャッシュ、ウォレットベースのアクセス、直接決済インフラとして利用します。

個人

個人は Judecoin をプライベートな電子キャッシュとして使用します。

Judecoin は、完全な取引履歴を公開せずに価値を送信、受信、保管したい人々のために設計されています。

  • 金融プライバシーを重視するユーザー
  • 検閲耐性のある決済を必要とするユーザー
  • 自分の資金を自分で管理したいユーザー
  • 分散型デジタルマネーを好むユーザー
  • 銀行や決済仲介者への依存を減らしたいユーザー
  • 直接的な国境越えの価値移転を必要とするユーザー

Judecoin は、個人にデジタル取引における管理権、プライバシー、自由を提供します。

ウォレットユーザー

ウォレットユーザーは、デスクトップ、モバイル、またはコマンドラインウォレットを通じて Judecoin を利用します。

ウォレットでは次のことができます。

  • JUDE を受け取る
  • JUDE を送る
  • 残高を確認する
  • アドレスを管理する
  • アカウントをバックアップし復旧する
  • Judecoin ネットワークに接続する

ウォレットユーザーは、実際のネットワーク活動の基盤です。

事業者と決済ユーザー

事業者と決済ユーザーは、Judecoin をプライベートで低コストかつ直接的なデジタル決済に使用できます。

想定される利用例には次のものがあります。

  • 直接決済
  • オンライン決済
  • 越境決済
  • 事業者決済
  • プライベート決済
  • デジタル商取引

Judecoin は事業者に、自動チャージバックがなく、従来型決済仲介者への依存を減らした代替的なデジタルキャッシュ手段を提供します。

ネットワークを運用する

運用者は、公開ネットワークを観測、維持、監視、利用しやすい状態に保ちます。

Service Node運用者

Service Node 運用者は Judecoin の分散型インフラを支えます。

Proof of Stake により、Service Node 運用者はネットワーク運用、安定性、長期的なエコシステム開発に参加します。

Service Node 運用者は次のことができます。

  • 安定したノードを運用する
  • 稼働時間を維持する
  • ノード状態を監視する
  • アップグレード手順に従う
  • ネットワークの安全性を支援する
  • 分散型インフラを支える
  • Judecoin の長期的な発展に参加する

強力な Service Node 運用者基盤はネットワークを強化します。

インフラ運用者

インフラ運用者は、Judecoin ネットワーク周辺のツールとシステムの維持を支援します。

取り組む対象には次のようなものがあります。

  • ノード
  • ブロックエクスプローラー
  • 監視ツール
  • ネットワークステータスページ
  • Service Node ダッシュボード
  • 公開統計リソース
  • デプロイ自動化
  • ネットワーク健全性ツール

インフラ運用者は、Judecoin を観測、維持、利用しやすいものにします。

システムを改善する

開発者と研究者は、エコシステムのソフトウェア、セキュリティ、プライバシー、ツール、長期的な信頼性を改善します。

開発者

開発者は Judecoin エコシステムを構築し改善します。

開発者の貢献には次のようなものがあります。

  • ウォレット改善
  • デーモンソフトウェア
  • Service Node ツール
  • RPC 連携
  • 監視ダッシュボード
  • アトミックスワップツール
  • クロスチェーンツール
  • ドキュメント更新
  • テストとデバッグ

開発者は Judecoin の長期的な成長と信頼性に不可欠です。

研究者

Judecoin は、プライバシー、暗号技術、ブロックチェーンセキュリティ、分散システム、クロスチェーン技術の研究と結びついています。

研究者は次の領域を研究または支援できます。

  • 取引プライバシー
  • リング署名
  • ゼロ知識証明との互換性
  • 検閲耐性
  • ウォレットセキュリティ
  • ネットワークレベルのプライバシー
  • ブロックチェーンの拡張性
  • アトミックスワップ設計
  • プロトコルセキュリティ

研究は、Judecoin がプライバシー重視の暗号通貨として改善を続けることを支えます。

普及を広げる

企業、ドキュメント貢献者、コミュニティ貢献者、新規ユーザーは、Judecoin を見つけやすく、理解しやすく、信頼しやすく、使いやすいものにします。

企業

企業は Judecoin を使って、デジタル資産決済やプライベートな金融ツールを好むユーザーにリーチできます。

企業は次のような利点を得られます。

  • 低コストの決済手段
  • 自動チャージバックなし
  • 新しい決済ユーザー
  • コミュニティ内での認知度
  • 越境決済
  • 直接的なデジタル取引

Judecoin を受け入れることで、企業はグローバルなデジタル通貨コミュニティとつながることができます。

ドキュメント貢献者

ドキュメント貢献者は、ユーザー、開発者、運用者が Judecoin の仕組みを理解できるよう支援します。

次のような形で貢献できます。

  • ガイドを改善する
  • 古いページを更新する
  • ドキュメントを整理する
  • 資料を翻訳する
  • 技術手順を修正する
  • より分かりやすい説明を書く
  • 公開ナレッジリソースを維持する

質の高いドキュメントは Judecoin の成長を加速し、新規ユーザーの混乱を減らします。

コミュニティ貢献者

コミュニティ貢献者は、教育、翻訳、テスト、コミュニケーション、エコシステム運営を通じて Judecoin の成長を支えます。

コミュニティでの貢献には次のようなものがあります。

  • ガイドを作成する
  • 資料を翻訳する
  • ユーザーの質問に答える
  • バグを報告する
  • 情報を整理する
  • 公開ドキュメントを改善する
  • 新規ユーザーを支援する
  • 公式アップデートを共有する
  • コミュニティリソースを構築する

強いコミュニティは、Judecoin をオープンで活発かつ強靭なものに保ちます。

新規ユーザー

新規ユーザーは、Judecoin とは何かを学び、ウォレットをインストールし、ウォレットのバックアップを理解し、公式アップデートを確認するところから始められます。

新規ユーザーは資金を送る前に、ウォレット情報の守り方、公式ソフトウェアの確認方法、プライベートなデジタル通貨の仕組みを理解しておく必要があります。

新しいユーザーが増えるたびに、Judecoin ネットワークは強化されます。

プライベートなデジタルキャッシュには、ユーザーと開発者の両方が必要です

Judecoin は、プライバシー、分散化、検閲耐性、開かれた金融インフラを重視する人々によって利用され、支えられています。

そのエコシステムには、個人ユーザー、ウォレットユーザー、Service Node 運用者、開発者、研究者、事業者、企業、インフラ運用者、ドキュメント貢献者、コミュニティ貢献者が含まれます。

JUDE は、プライベートなデジタルキャッシュを求めるユーザーと、次世代の分散型金融インフラを作りたい開発者のためのものです。
